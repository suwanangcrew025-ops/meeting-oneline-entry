One line that could have replaced an entire pointless meeting: forty minutes
spent deciding the meeting should have been an email, a follow-up meeting
booked to confirm the email, and the email printed, framed, and hung beside
the fire exit. `main.py` writes the 190-character line to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## Run it

```sh
python3 main.py
```
